# osvaldorivera.dev - Personal Portfolio & AI Agent UX Lab

A personal portfolio web application built with **Astro**, **TypeScript**, and **Tailwind CSS**, which is deployed automatically on **Vercel**

This repo serves as both my personal site and a hands-on lab to help me play with and learn TypeScript, experiment with Astro component architecture, and also test out some agentic coding. 

## Overview 

Instead of a single static design, this project uses a Multi-Layout Architecture. 

All portfolio data (experience, skills, capstone details, and labs) will live in a single directory "Source of Truth". The application will render this data across three interchangeable UI layout variants that visitors can toggle between in real time:

- **Default Layout** A hand-crafted, minimalist baseline layout built by myself to practice Astro, Tailwind, and TypeScript. 
- **Agent A Variant** A layout generated by Copilot in VS Code using a standardized master prompt
- **Agent B Variant** A layout generated by Gemini in Antigravity IDE using the exact same prompt for direct  UI/UX comparison. 


A lightweight header control will manage layout state and allow the visitor to swap between the three options.

## Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
